# C0.3 — Estado de red ligero: derivar valores que hoy cambian cada tick

Fase 0 · P1 · Worker: Sonnet (semántica de red delicada) · Auditor: Opus · Iteraciones máx: 3 · Pulido: no

## Objetivo

Varios `[Networked] float` cambian cada tick o cada frame y generan deltas continuos sin aportar información: la energía de la mirada, el progreso de bloqueo, el progreso para liberarse de la piedra (¡escrito desde `Update`!), el progreso de apagar la fogata y el pitch del campista. Todos son funciones lineales del tiempo entre eventos, así que se replican como **ancla + tick** (valor en el momento del último evento + `Runner.Tick` de ese momento) y cada cliente calcula el valor actual. El comportamiento visible debe ser **idéntico**. Métrica: en `PerfProbe` (C0.1) bytes/s salientes del campista y de un gnomo mientras enfoca/se libera bajan; cero escrituras networked en `Update`.

## Cambios exactos

Patrón común (escribir una vez como función de ayuda privada en cada clase, o una `static class NetAnchor` en `Scripts/Networking/NetAnchor.cs` con `float Elapsed(NetworkRunner runner, int anchorTick)` = `(runner.Tick - anchorTick) * runner.DeltaTime`, clamp ≥ 0):

### `CamperGaze.cs`

1. `Stamina` (float continuo) → `[Networked] float StaminaAnchor` + `[Networked] int StaminaTick`. Propiedad local `float CurrentStamina` que calcula: si `IsFocusing`: `StaminaAnchor - Elapsed/_staminaSeconds`; si no: `StaminaAnchor + max(0, Elapsed - _regenDelay)/_regenSeconds`; clamp 0..1. El ancla se re-escribe **sólo** cuando cambia `IsFocusing`, cuando se agota (`IsExhausted = true`) o al empezar la partida (`HandleGameStarted`). La autoridad usa `CurrentStamina` para decidir agotamiento y recuperación en `UpdateFocus`; `_sinceFocus` desaparece (se deriva). `StaminaFraction` público devuelve `CurrentStamina`.
2. `Progress` (0..1 del bloqueo) → `[Networked] int LockTick` (tick en que se fijó `Target`) **más `[Networked] NetworkBool LockFull`**, que sólo la autoridad pone a true cuando su fill derivado llega a 1 (y a false al fijar o soltar). `LockProgress` = `LockFull ? 1 : min(derivado, 0.99)`. **Lección de la auditoría:** un valor derivado del tick local sirve para presentación, pero **no para una decisión que toma otro peer** (el gnomo se congela a sí mismo): con latencia extrapolaría el bloqueo y se petrificaría aunque el campista ya hubiera soltado. Toda decisión cruzada necesita una confirmación replicada por la autoridad que la toma.
3. `Pitch`: escribir sólo si `Mathf.Abs(nuevo - Pitch) > 0.5f` (sigue siendo un float, pero deja de cambiar cada tick con el ruido del ratón).

### `Petrifiable.cs`

4. `NetBreakProgress` (escrito cada frame en `Update` con decaimiento) → `[Networked] float BreakAnchor` + `[Networked] int BreakTick`. `BreakProgress` = `max(0, BreakAnchor - max(0, Elapsed(BreakTick) - _decayDelay) * _decayPerSecond)`. Cada pulsación: `BreakAnchor = BreakProgress + 1; BreakTick = Runner.Tick` (escritura sólo al pulsar, ≤ 10/s). Al congelar y al liberar: ancla 0. **Mover la escritura fuera de `Update`**: `Update` sólo registra la pulsación en un contador local (`_pendingPresses`) y `FixedUpdateNetwork` (autoridad) la aplica al ancla y evalúa la liberación. El sonido de pulsación y `PressCount` siguen en `Update` (local).
5. `_sinceLastPress` desaparece (se deriva del ancla).

### `FireplaceManager.cs`

6. `DouseProgress` → `[Networked] float DouseAnchor` + `[Networked] int DouseTick`. `DouseFraction`/`IsBeingDoused`/`UpdateLabel` usan un `CurrentDouse` derivado con el mismo decaimiento (`_douseDecayDelay`, `_douseDecayPerSecond`). `RPC_RequestDouse` escribe `DouseAnchor = CurrentDouse + 1; DouseTick = Runner.Tick` y apaga si `≥ RequiredDousePresses`. El bloque de decaimiento en `FixedUpdateNetwork` se elimina (ya no hace falta); al apagarse o prender, ancla 0. `OnDouseProgressChanged` pasa a comparar `CurrentDouse` en `Render` (el `OnChangedRender` del ancla sigue sirviendo para el sonido de cada pulsación).

### `PlayerMovement.cs`

7. `AnimationMovement`: cuantizar a pasos de 0,05 antes de escribir y escribir sólo si cambia (`Mathf.Round(x * 20f) / 20f`). Sin cambios en `Render`.
