# C1.6a — Torre tótem: petrificar la base congela toda la torre

Fase 1 · P1 · Worker: Sonnet · Auditor: Opus (estado derivado entre peers con autoridad distinta) · Iteraciones máx: 3

## Objetivo
Dar riesgo real a la torre de gnomos: si el campista petrifica al gnomo de abajo, toda la torre queda congelada (los de arriba no pueden bajarse ni moverse) hasta que la base se libera; patear la base sigue derrumbándola (ya existe). Métrica: en V2, petrificar la base de una torre de 3 congela a los 3 y el momento da risa.

## Lee antes
`CLAUDE.md` (regla 4: decisión de otro peer = bool replicado por su autoridad), `Docs/plan/README.md`, `Player/GnomeStack.cs` (montura, `IsRiding`, `RidersAbove`, `ChainHasCrouching` de C1.2 como patrón), `Gaze/Petrifiable.cs` (`IsStone`, liberación machacando E), `Gaze/CamperGaze.cs` (sólo para entender a quién apunta), `Player/PlayerMovement.cs` (cómo se bloquea el movimiento de un petrificado).

## Cambios exactos
1. `GnomeStack`: `public bool IsTowerFrozen` = alguien de la cadena **por debajo** (montura, su montura…) tiene `Petrifiable.IsStone` replicado. Se deriva en cada peer; sin `[Networked]` nuevo (el `IsStone` ya lo replica la autoridad de cada gnomo).
2. Un jinete con `IsTowerFrozen`: no puede bajarse (`Jump`/desmontar bloqueado), no puede pasar objetos ni subir más, no gira el cuerpo; su cámara sí puede mirar (como el petrificado). No puede machacar E para liberarse él (sólo la base se libera).
3. Presentación en `Render` en todos los peers: el jinete congelado usa el mismo tinte/feedback de piedra que `Petrifiable` (reutilizar el mismo método/material si existe; si no, exponer en `Petrifiable` un método de presentación `SetStoneLook(bool)` y llamarlo desde `GnomeStack`).
4. HUD local del jinete congelado: texto «¡La torre está petrificada!» (reutilizar el overlay de piedra de C0.7 si `GazeFeedbackHUD` lo permite con una línea; si no, sólo el tinte — no tocar el HUD en esta tarjeta si cuesta más).
5. Cuando la base se libera o es pateada (derrumbe), todos vuelven a la normalidad (derivado, sin RPC).
6. Telemetría (autoridad del jinete, una línea): `tower_frozen` (altura de la torre).

## Qué NO hacer
No tocar `Carryable`, `PlayerInteractor`, `InteractionPrompt` (C1.6b trabaja en paralelo). No añadir RPC. No cambiar cómo se petrifica la base.

## Validación
- V1: ningún peer decide sobre otro sin bool replicado; sin asignaciones por frame; late joiner ve la torre congelada; migración del master irrelevante (jugadores con autoridad propia); un jinete que se va no rompe a la base.
- V2: torre de 2 y de 3, petrificar la base: todos congelados con tinte de piedra; base machaca E: todos libres; patear la base congelada: se derrumba como antes.

Reporte ≤ 20 líneas.
