# Fase 10 — Debate de optimización

Dos agentes con enfoques opuestos debaten por escrito, por rondas, cómo hacer que GnoMore Campers gaste menos recursos. Sólo analizan: nada se implementa hasta que el equipo elija.

- **A · Ahorrador**: `debate-A-rondaN.md`. Recorta CPU, GPU, memoria, tamaño de build y ancho de banda.
- **B · Escéptico**: `debate-B-rondaN.md`. Exige pruebas, defiende la jugabilidad y el aspecto, busca la causa real antes de recortar y propone alternativas.
- Resultado: `conclusiones.md`.
